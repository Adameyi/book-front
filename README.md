# book-front

**Live Demo:** (https://book-front-library.vercel.app/)


A digital library platform designed to manage and deliver a wide range of books, articles, and educational resources. The website allows users to browse, search, and read digital content with features like user authentication, reading progress tracking, and content categorization.

-------INSTALLATION--------

**Clone the repository:**
git clone <repository-url>
cd <project-folder>

**Install backend dependencies:**
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

**Run Django migrations:**
python manage.py migrate

**Install frontend dependencies:**
cd ../frontend
npm install

**Start the backend:**
cd ../backend
python manage.py runserver

**Start the frontend in a new terminal:**
cd frontend
npm run dev
